# Claude Code - 코드 검색 및 탐색

Grep, Glob, Task 도구를 활용한 코드베이스 탐색 방법을 학습합니다.

## Glob 도구

### 파일 패턴 검색

```
src/**/*.ts 파일을 찾아줘.
```

**결과:** 모든 TypeScript 파일 목록

### 특정 파일 찾기

```
**/config*.json 파일을 찾아줘.
```

**활용:**
- 설정 파일 찾기
- 특정 확장자 파일 찾기

## Grep 도구

### 코드 검색

```
프로젝트에서 "console.log"를 검색해줘.
```

**결과:** console.log가 있는 모든 파일과 라인

### 정규식 검색

```
"function \w+\(" 패턴을 검색해줘.
```

**활용:**
- 함수 정의 찾기
- TODO 주석 찾기
- 특정 API 호출 찾기

### 파일 타입 필터

```
TypeScript 파일에서 "async function"을 검색해줘.
```

## Task 도구

### 코드베이스 탐색

```
프로젝트 구조를 파악해줘.

주요 파일과 폴더:
- src/ 구조
- 설정 파일들
- 엔트리 포인트
```

**활용:**
- 새 프로젝트 이해
- 아키텍처 분석

### 특정 기능 찾기

```
사용자 인증이 어떻게 구현되어 있는지 찾아줘.

확인 사항:
- 로그인 로직 위치
- JWT 사용 여부
- 미들웨어 구현
```

## 실전 프롬프트 예시

### API 엔드포인트 찾기

```
프로젝트의 모든 API 엔드포인트를 찾아줘.

패턴:
- router.get
- router.post
- router.put
- router.delete

각 엔드포인트의 경로와 파일 위치를 정리.
```

### 사용되지 않는 코드 찾기

```
다음 함수가 어디서 사용되는지 찾아줘:

- validateEmail
- hashPassword
- generateToken

사용되지 않으면 제거 제안.
```

### 의존성 분석

```
프로젝트가 사용하는 외부 라이브러리를 분석해줘.

확인:
- package.json
- import 문
- 실제 사용 여부
```
