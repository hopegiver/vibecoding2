# .claude/commands 활용 가이드

> **이 문서는 구버전입니다.** `.claude/commands/`는 `.claude/skills/`로 통합되었습니다.
>
> **→ [.claude/skills 활용 가이드](claude-skills.md)로 이동하세요.**

## 호환성

기존 `.claude/commands/*.md` 파일은 **계속 작동합니다.** 마이그레이션은 선택 사항입니다.

Skills로 전환하면 자동 트리거, Subagent 실행, 동적 컨텍스트 등 추가 기능을 사용할 수 있습니다.
