# 문서 제작 규칙

## 필수 사항

### 구조
- 모든 문서는 `docs/` 폴더에 `.md` 파일로 작성
- 첫 줄은 `# 제목` (H1) 으로 시작
- 문서 하단에 관련 문서 링크 ("다음 단계" 또는 "관련 문서") 포함
- 문서 맨 아래에 `[← 목차로 돌아가기](../_sidebar.md)` 포함
- 새 문서 추가 시 `_sidebar.md`에 반드시 등록

### 언어 및 톤
- 한국어로 작성
- 경어체 사용 (~합니다, ~하세요)
- 간결하고 실용적인 톤

### 코드 예제
- 코드 블록에 언어 태그 필수 (```javascript, ```html, ```jsp, ```bash 등)
- ✅/❌ 대비 패턴으로 올바른/금지 예제 병렬 제시
- 예제는 실제 동작하는 코드 기반으로 작성
- 설명 코드가 아닌 복사-붙여넣기 가능한 코드 제공

### 파일명
- 플랫폼별 접두사: `malgn-`, `pages-`, `workers-`
- 공통 문서: 기능명 그대로 (예: `coding-rules.md`, `security.md`)
- kebab-case 사용 (예: `code-review-checklist.md`)

### 내용 품질
- 개요 섹션에서 "왜 필요한가"를 먼저 설명
- 이론보다 실전 예제 중심
- 체크리스트 형태로 요약 제공 (가능한 경우)
- 플랫폼별 차이가 있는 내용은 명확히 구분하여 작성

## 금지 사항
- 영어 전용 문서 작성 금지
- 코드 블록 언어 태그 생략 금지
- `_sidebar.md` 미등록 상태로 문서 추가 금지
- `docs/` 외 경로에 가이드 문서 배치 금지 (VIEWLOGIC.md, README.md는 예외)
- 500줄 초과 단일 문서 금지 (분리 필요)
